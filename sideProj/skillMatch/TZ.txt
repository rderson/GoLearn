Ну вообще в чем заключается суть проекта:

Сделать (веб-)приложение которое будет на основе написанного пользователем резюме с помощью нейросети(-сетей) искать для тебя максимально подходящие тебе вакансии. Для кандидата таким образом процесс поиска облегчается, а работадатель быстрее находит подходящих ему кадров. Таким образом в выигрыше будет и работодатель и кандидат.

Требования:

1. Определить требования (какие именно параметры должно содержать резюме)
2. База данных вакансий/резюме и работадателей
3. Нейросеть которая будет анализровать резюме и искать ключевые слова 
4. Тестовые кейсы
5. Сервер на котором будет работать приложение
6. Определиться с тем как будет выглядеть интерфейс

Backend: Go
Database: PostgreSQL

Resumes:    ID (Primary key) | candidate_id (foreign) | contact_info | summary | skills | experience | education | uploaded_at 
Vacancies:  ID (Primary key) | title | description | company_id (foreign) | location | required_skills | salary_range | employment_type | posted_at
Employers:  ID (Primary key) | company_name | contact_info | description | created_at
Candidates: ID (Primary key) | name | email (unique) | password_hash | contact_info | created_at
